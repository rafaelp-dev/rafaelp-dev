## 📌 Projetos em destaque

### Workout

Sistema de gerenciamento de treinos desenvolvido para uso pessoal e evolução técnica.

Funcionalidades:

* Cadastro de treinos
* Controle de exercícios
* Registro de séries, cargas e repetições
* Histórico de evolução
* Autenticação com JWT

### 🌱 Cozy Restoration Game

Projeto conceitual de jogo focado em restauração ambiental e experiência relaxante.

Elementos principais:

* Limpeza e recuperação de ecossistema
* Feedback visual e sonoro satisfatório
* Progressão sem punição pesada
* Educação ambiental integrada ao gameplay
